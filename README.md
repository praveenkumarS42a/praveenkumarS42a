### 📚 RAG-Based Document Question Answering System

An intelligent document question-answering application that allows users to interact with documents using natural-language queries. Built using Retrieval-Augmented Generation (RAG), the system retrieves relevant information through semantic search and generates context-aware responses using an LLM.

- 📄 Document ingestion and text extraction for processing uploaded documents
- ✂️ Text chunking to divide documents into manageable sections
- 🧠 Embedding generation to convert document content into vector representations
- 🔍 Semantic similarity search using ChromaDB for retrieving relevant document chunks
- 🤖 LLM-powered response generation using retrieved context to provide grounded answers and reduce hallucinations
- ⚡ FastAPI backend integration for handling document processing and question-answering requests

**Architecture:**

`Document Ingestion → Text Extraction → Chunking → Embeddings → Vector Database → Semantic Retrieval → LLM Response Generation`

**Stack:** `Python` `RAG` `LLM` `Embeddings` `ChromaDB` `FastAPI` `Vector Search`

**GitHub Repository:** [RAG-Based Document Question Answering System](https://github.com/praveenkumarS42a/RAG-based-Document-Question-Answering-System)
